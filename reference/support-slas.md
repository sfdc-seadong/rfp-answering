| Capability | Native? | Notes |
|---|---|---|
| Standard Support (online case submission) | Yes | 2-business-day response, included in all editions |
| Premier Support (24/7 phone, 1-hr Sev1) | Yes (add-on) | Developer support, expert coaching, accelerated routing |
| Signature Success (TAM, proactive monitoring) | Yes (add-on) | Top-tier; designated Technical Account Manager |
| Trailhead learning platform | Yes | Free, gamified, 1,000+ modules |
| Trailhead Academy (instructor-led) | Yes | Virtual and in-person training |
| Certification program | Yes | Admin, Developer, Architect, Consultant, Marketer tracks |
| Expert coaching sessions (Accelerators) | Yes (add-on) | Premier and Signature benefit |
| myTrailhead (custom-branded learning) | Yes | Organization-specific training content |
| Trust status portal (trust.salesforce.com) | Yes | Real-time and historical availability data |
| Community forums | Yes | Trailblazer Community peer support |
