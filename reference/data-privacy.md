## Key Native Capabilities

When reference URLs fail or return thin results, use this section as a fallback. These capabilities are natively available and should not be described as requiring custom build or external tools.

| Capability | Native? | Notes |
|---|---|---|
| Data Processing Addendum (DPA) with SCCs | Yes | Included in Master Subscription Agreement |
| Binding Corporate Rules (BCRs) | Yes | Approved for Processor activities |
| Published sub-processor list | Yes | Advance notice of changes per DPA terms |
| GDPR data subject rights support | Yes | Erasure, portability, rectification via platform features |
| CCPA/CPRA compliance support | Yes | Consumer privacy rights via platform features |
| Hyperforce data residency (region selection) | Yes | Customer-selected geographic deployment |
| Government Cloud (US data only) | Yes | FedRAMP-authorized infrastructure |
| Data classification labels | Yes | Native field-level sensitivity tagging |
| Privacy Center | Yes (add-on) | Automated data retention, right-to-be-forgotten policies |
| Consent management (Individual object) | Yes | Track and enforce consent preferences |
| Einstein Trust Layer (AI data privacy) | Yes | No customer data used for model training; data masking before LLM |
| Data export (API, Data Loader, Export Service) | Yes | Self-service data portability |
| Field Audit Trail | Yes (add-on) | 10-year field history retention for compliance |
| Recycle Bin (soft delete recovery) | Yes | 15-day recovery window for deleted records |
